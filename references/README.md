# UM CORTE — Reference Library

This folder contains audiovisual references for V8.5.

These files are NOT automatically instructions to copy something exactly.

They exist to communicate:

- mood;
- timing;
- impact;
- motion;
- composition;
- sound identity;
- visual language;
- animation behavior;
- atmosphere.

When using a reference, first understand WHY it works.

Do not reduce a reference to:

> same color + similar particles.

Identify the important qualities and adapt them to UM CORTE.

---

# Folder Structure

## `/visual`

Use for:

- screenshots;
- concept art;
- character references;
- UI references;
- arena references;
- VFX references;
- equipment references;
- animation poses.

---

## `/audio`

Use for sound references.

Examples:

- activation sounds;
- transformation sounds;
- impact sounds;
- time-stop transitions;
- adaptation cues;
- power-specific audio identity.

Audio files are references unless explicitly marked as production assets.

Do not assume a reference audio file is legally intended for final distribution.

---

## `/video-frames`

Use for important frames extracted from video references.

Prefer a small number of useful frames instead of hundreds of nearly identical images.

Frames should communicate things such as:

- beginning of an effect;
- buildup;
- peak impact;
- final state;
- lighting change;
- character pose;
- environment reaction.

---

# How to use references

For each major redesign:

1. inspect the relevant references;
2. identify the essential qualities;
3. compare them with the current implementation;
4. propose how those qualities can be translated into UM CORTE;
5. preserve gameplay readability;
6. implement a small test;
7. evaluate before expanding.

---

# Reference fidelity

Some references are especially important to the intended fantasy.

When the project documentation or user explicitly says that a reference must strongly preserve its recognizable feeling, treat that seriously.

Examples may include:

- The World;
- Sandevistan;
- Mahoraga;
- ROOM.

For these cases, timing, sound, environmental reaction and presentation may matter as much as the core visual shape.

Do not silently replace a specific reference with a generic interpretation.

If the supplied material is insufficient to understand the intended effect, ask for clarification or additional reference material.

---

# Gameplay always remains readable

References must never justify making combat impossible to read.

Preserve:

- telegraphs;
- hit timing;
- attack direction;
- dangerous zones;
- projectile visibility;
- parry readability;
- character visibility.

Cinematic presentation should reinforce the mechanic.

Not hide it.

---

# Original interpretation

UM CORTE should not become a collage of other games and media.

References should help communicate quality and feeling.

The final result should still feel like UM CORTE.

When possible:

> preserve the fantasy, timing and emotional effect;

while:

> adapting form, composition and execution into the visual language established for V8.5.
