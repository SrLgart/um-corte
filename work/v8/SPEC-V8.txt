Quero que você implemente a V8 do UM CORTE partindo da versão atual do projeto.

LEIA E ENTENDA TODO O CÓDIGO ATUAL ANTES DE MODIFICAR QUALQUER COISA.

Esta especificação é a fonte de verdade da V8.

NÃO simplifique sistemas descritos aqui.
NÃO substitua mecânicas por versões genéricas só para terminar mais rápido.
NÃO remova recursos existentes.
NÃO reformule a arquitetura final para múltiplos arquivos como mudança de produto.

Atualizar também histórico/changelog/versionamento interno para V8.

======================================================================
1. PRINCÍPIOS DO UM CORTE
======================================================================

UM CORTE continua sendo um jogo em que:

- um golpe limpo mata;
- NÃO existe barra de HP convencional;
- combate depende de posicionamento, spacing, leitura, parry, movimentação e timing;
- poder não deve substituir habilidade;
- Legados podem criar situações absurdas, mas ainda devem gerar interação;
- ataques precisam continuar legíveis;
- não transformar inimigos ou bosses em esponjas de dano;
- não adicionar HP apenas para artificialmente aumentar dificuldade;
- bosses também obedecem a filosofia de um golpe por duelo, salvo efeitos explícitos de Legados como Armadura de Cristal/Berserker etc.

A V8 NÃO terá campanha narrativa.
Campanha está adiada para outra versão.

O foco da V8 é:

1. Caminho do Guerreiro
2. Sistema completo de Legados
3. Combat AI 2.0
4. 12 bosses
5. 5 arenas exclusivas do Caminho
6. rework visual dos ataques/slashes
7. rework da corrida do Corredor
8. integração de Legados com outros modos
9. interface completa de Legados
10. save/continue do Caminho

4. SISTEMA CENTRAL DE LEGADOS
======================================================================

Criar um sistema central e único de Legados.

IMPORTANTE:

Cada Legado deve existir UMA VEZ no código.

Os modos NÃO devem possuir cópias independentes da lógica do mesmo Legado.

Diferentes modos só mudam:
- como o Legado é adquirido;
- se ele está elegível;
- quando reseta;
- regras de draft.

Usar um registry central de Legados.

Sugestão conceitual de dados para cada Legado:

id
name
category
rarity
description
controlDescription
stackable
activeType
defaultBinding
usageScope
modeEligibility
requiresWeapon
iconRenderer / iconAsset
worldRepresentation
onAcquire
onRemove
onRoundStart
onMatchStart
onAttack
onParry
onPerfectParry
onDash
onKill
onDeath
onUpdate
etc.

Não precisa seguir exatamente esses nomes, mas a arquitetura deve permitir isso.

Categorias:

1. Armas
2. Vestimentas
3. Relíquias
4. Técnicas
5. Invocações
6. Poderes

Raridades:

- COMUM
- RARO
- LENDÁRIO

Cor da UI/estilo pode respeitar raridade, mas sem poluir.

Por padrão, Legados NÃO acumulam consigo mesmos.

Se o jogador já possui um Legado:
ele não deve aparecer novamente num draft.

Só permitir repetição quando aquele Legado estiver explicitamente marcado como stackable.

Atualmente, assumir os Legados da V8 como não-stackable, salvo caso futuro.

======================================================================
5. REPRESENTAÇÃO VISUAL DOS LEGADOS
======================================================================

Todo Legado deve possuir:

1. ÍCONE DE INTERFACE
2. REPRESENTAÇÃO VISUAL NO JOGO

Isso NÃO significa necessariamente literalmente dois sprites estáticos.

Exemplos:

Arma:
- ícone
- arma equipada no personagem

Vestimenta:
- ícone
- peça visual no personagem

Invocação:
- ícone
- criatura/entidade na arena

Relíquia:
- ícone
- pequeno objeto, símbolo, aura ou manifestação quando ativa

Técnica:
- ícone
- pose/animação/VFX próprio da técnica

Poder:
- ícone
- manifestação visual/VFX dentro da arena

O personagem deve visualmente contar a história da build.

Entretanto:
NÃO transformar um jogador avançado numa pilha ilegível de sprites.

Criar sistema de prioridade visual:

- equipamentos principais ficam visíveis
- acessórios menores ficam discretos
- relíquias podem aparecer apenas como detalhes
- efeitos temporários se manifestam somente quando ativam
- se várias vestimentas ocuparem a mesma região corporal, combinar visualmente de maneira limpa

NÃO limitar combinações mecânicas só porque duas peças ocupariam a mesma parte do corpo.

Exemplo:
Bota Alada + Botas-Foguete + Botas Magnéticas DEVEM poder funcionar juntas.

======================================================================
6. HUD DISCRETA DOS LEGADOS
======================================================================

Durante combate, mostrar discretamente TODOS os Legados adquiridos.

Local:
canto inferior esquerdo.

Visual:

- somente ícones
- pequenos
- sem nome
- sem descrição
- sem caixas grandes
- sem excesso de bordas
- sem “frufru”

Organizar na ORDEM DE AQUISIÇÃO.

Quando houver muitos:
- quebrar em segunda linha
- reduzir levemente o tamanho se necessário
- manter legibilidade

Legados consumidos durante a run não desaparecem necessariamente da lista.

Exemplo:
Pedra Filosofal consumida:
mostrar ícone apagado/rachado.

A lista inferior esquerda serve para:
“olhar rapidamente e lembrar da build”.

NÃO usar essa fita como inventário detalhado.

7. TAB — PAINEL COMPLETO DOS LEGADOS
======================================================================

TAB abre o painel de Legados.

No Caminho/PvE/Training offline:
TAB pausa.

No online:
TAB NÃO pausa a partida.

No online:
remapeamentos grandes devem preferencialmente ser feitos entre duelos/rounds para evitar acidentes.

Painel deve mostrar categorias:

ARMAS
VESTIMENTAS
RELÍQUIAS
TÉCNICAS
INVOCAÇÕES
PODERES

Cada Legado mostra:

- ícone
- nome
- raridade
- descrição
- como usar
- cooldown, se houver
- limite de uso
- tecla atual, se houver
- estado consumido/disponível

Quando passar o mouse sobre um Legado:

Exemplos:

Bota Alada -> pés destacam
Máscara de Pedra -> máscara destaca
Machado Leviatã -> arma destaca
Corvo -> corvo destaca

======================================================================
8. KEYBINDINGS DOS LEGADOS ATIVOS
======================================================================

Criar slots gerais de ações especiais:

1 até 9

Quando um Legado exige botão próprio:
atribuir automaticamente ao primeiro slot livre.

Exemplo:

primeiro ativo -> 1
segundo -> 2
terceiro -> 3

Mas esses são apenas DEFAULTS.

No TAB:
permitir remapear para outras teclas/botões válidos.

Exemplos:
E
Q
Mouse4
Mouse5
1
2
3
etc.

Se uma tecla estiver ocupada:
avisar antes de substituir.

Legados que já usam controles naturais NÃO precisam ocupar slot.

Exemplo:

Machado Leviatã:
M1 = ataque
segurar M1 = arremessar
M1 novamente quando longe = recall

Isso não precisa ocupar 1–9.

Se houver mais ativos do que slots automáticos:
marcar extras como “sem tecla atribuída” até o jogador remapear.

No networking:
NÃO sincronizar a tecla física.
Sincronizar a AÇÃO SEMÂNTICA do Legado.

Exemplo:
o jogador pode usar The World no E localmente,
mas a rede recebe algo como activateLegacy("star_platinum_world").

======================================================================
9. TERMINOLOGIA DE RESET
======================================================================

Usar estes conceitos de forma consistente:

DUELO:
uma rodada individual que termina quando alguém morre.

PARTIDA:
o confronto completo daquele nível, composto pelos duelos do formato atual do jogo.

NÍVEL:
uma partida dentro do Caminho do Guerreiro.

RUN:
a sequência completa do Caminho até o nível 50 ou até derrota.

Tipos de uso:

“1x por duelo”
-> reseta no próximo duelo.

“1x por partida”
-> reseta somente no próximo nível/confronto.

“1x por run”
-> não volta até a run terminar.

10. CATÁLOGO COMPLETO — ARMAS
======================================================================

ARMAS COMUNS:

1. VASSOURA
- alcance razoavelmente bom
- ataque relativamente lento
- cobertura ampla
- arma improvisada
- fácil de entender

2. ESPADA
- comportamento base semelhante à espada do Cavaleiro
- equilibrada
- referência vanilla da categoria

3. ARCO
- ataque à distância
- pequeno tempo de puxada
- aproximadamente 3 segundos entre tiros
- flecha legível
- flecha colide com paredes/plataformas
- flecha pode ser aparada
- parry deve desviar/refletir adequadamente

4. SOCO-INGLÊS
- alcance extremamente curto
- ataques muito rápidos
- sensação semelhante ao Pugilista
- NÃO concede automaticamente o kit completo do Pugilista

5. MACHADO
- ataque pesado
- arco amplo
- alcance médio
- startup/recovery maiores que espada
- leitura forte

6. KUNAI
- projétil de curto/médio alcance
- cooldown aproximadamente 1–1.5s
- trajetória reta
- parryable
- para/cai após distância razoável

--------------------------------------------------

ARMAS RARAS:

7. MACHADO LEVIATÃ
Referência God of War.

M1:
ataque melee normal.

Segurar M1:
arremessa o machado.

Quando o machado está longe:
M1 chama o machado de volta.

O machado:
- mata indo
- mata voltando
- colide com cenário quando adequado
- é fisicamente visível

Enquanto está longe:
jogador fica desarmado.

8. AGULHA
Inspiração Hollow Knight / Silksong.

Identidade principal:
POGO.

Permitir pogo:
- em inimigos
- em superfícies válidas
- inclusive no chão

Pogo deve devolver impulso vertical.

É híbrido de combate e mobilidade.

9. GUNBLADE
Inspiração FFVIII.

Ataque normal:
corte de espada.

Durante janela específica no impacto:
input adicional de trigger cria disparo/impacto extra.

O valor mecânico vem do timing dentro do timing.

10. BACAMARTE
- tiro muito curto
- espalhamento largo
- quase instantâneo
- um disparo muito perigoso
- reload/cooldown longo
- possível pequeno recoil aéreo

11. IOIÔ
Inspiração Terraria.

Segurar M1:
lança e mantém ioiô ativo.

Controle:
posição/direção influenciada pela mira dentro de raio máximo.

Soltar M1:
retorna.

Regras:
- não atravessa parede
- medium range
- tempo ativo limitado
- cooldown curto após retorno
- ameaça persistente
- parryable

--------------------------------------------------

ARMAS LENDÁRIAS:

12. YAMATO
Referência Devil May Cry.

M1:
corte rápido.

Segurar M1:
breve postura de bainha/preparação.

Durante preparação:
marcar direção/área.

Soltar:
gera corte instantâneo à distância.

NÃO é projétil viajando.

É literalmente um corte espacial aparecendo na região.

13. RUYI JINGU BANG
Bastão do Rei Macaco.

M1:
ataque normal rápido.

Segurar M1:
bastão se estende violentamente a enorme distância.

Se apontado contra o chão:
extensão pode lançar o jogador para cima.

Mistura:
arma
controle de espaço
mobilidade

14. ZENITH
Inspiração Terraria.

Ataque:
golpe principal + 2 ou 3 lâminas espectrais adicionais atravessando trajetórias ao redor da região ofensiva.

Não copiar exatamente Terraria.
Adaptar ao UM CORTE.

15. LÂMINA DO ECO
Original.

Ataque acontece normalmente.

Aproximadamente 0.6s depois:
o EXATO MESMO CORTE reaparece no MESMO ESPAÇO DO MUNDO onde ocorreu originalmente.

Não seguir o jogador.

Mostrar fissura/eco visual discreto avisando onde o segundo corte acontecerá.

11. CATÁLOGO COMPLETO — VESTIMENTAS
======================================================================

VESTIMENTAS COMUNS:

1. BOTA ALADA
+1 salto aéreo adicional.

2. SANDÁLIAS DO VENTO
aumento perceptível de velocidade base de corrida.

3. JOELHEIRAS
slide:
- percorre distância maior
- mantém fluidez
- melhora eficiência

4. LUVAS DE ESCALADA
Ao segurar direção contra a parede:
personagem trava completamente na parede.

Não desliza.

Soltar direção:
desgruda.

Pular:
wall jump normal.

Não usar stamina inicialmente.

5. CAPA LEVE
Segurar pulo enquanto cai:
reduz velocidade de queda.

Não é glide completo.

6. FAIXA DO DUELISTA
reduz recovery de um parry errado/missed parry.

VESTIMENTAS RARAS:

7. MANTO SOMBRIO
Dash vira Shadow Dash.

Durante parte curta do dash:
- intangível contra ataques
- atravessa inimigos

Ótimo para cross-up.

NÃO atravessa paredes sólidas.

8. CAPA PLANADORA

glide verdadeiro.

- mantém deslocamento horizontal
- queda lenta
- soltar fecha
- controle claro

9. ARMADURA DE CRISTAL
Bloqueia 1 golpe mortal por PARTIDA.

Ao bloquear:
- estilhaça visualmente
- perde proteção até próxima partida

No próximo nível/confronto:
reconstrói.

10. BOTAS MAGNÉTICAS
Ao segurar contra parede:
permite correr ao longo dela por período curto.

11. MANTO DO ESPELHO

deixa afterimage convincente na posição inicial.

Afterimage:
- não ataca

12. BOTAS-FOGUETE
No ar:
segurar pulo aciona pequenos propulsores.

Usa combustível curto.

Combustível:
- recarrega somente ao tocar chão/plataforma

VESTIMENTAS LENDÁRIAS:

13. ARMADURA DO BERSERKER
1x por PARTIDA.

Quando o jogador recebe golpe mortal:
não morre imediatamente.

Entra em estado de fúria por aproximadamente 2 segundos.

Se matar um inimigo dentro desse período:
sobrevive.

Se não matar:
morre ao terminar o período.

Visualmente:
armadura ativa/fecha e personagem entra em estado agressivo.

14. ASAS DE ÍCARO
Voo real limitado.

Ao ativar:
permitir deslocamento aéreo controlado.

Usar barra de energia curta.

Não permitir voo infinito.

15. TRAJE FANTASMA
Dash atravessa GEOMETRIA do mapa.

Pode passar:
- paredes
- plataformas válidas

Precisa de proteção contra:
- softlock
- sair permanentemente da arena
- ficar preso em collider

16. MÁSCARA DE PEDRA
Referência JoJo.

Transformação vampírica.

Concede:
- movimentação mais predatória
- wall cling natural
- saltos mais agressivos
- matar inimigo restaura imediatamente recursos de mobilidade como dash/air dash/pulos relevantes

Não adicionar HP.

17. MANTO DA GRAVIDADE
Ação ativa.

Inverte a gravidade SOMENTE do próprio personagem.

Chão vira teto.

Nova ativação:
volta gravidade ao normal.

Integrar corretamente com:
- plataformas
- dash
- wall systems
- ataques
- câmera
- fatal fall logic

======================================================================
12. CATÁLOGO COMPLETO — RELÍQUIAS
======================================================================

RELÍQUIAS COMUNS:

1. SINO DE GUERRA
Perfect Parry:
recarrega imediatamente dash.

2. AMPULHETA RACHADA
Ao matar inimigo:
restaurar recursos de movimentação:
- dash
- air dash
- saltos aéreos

3. OLHO DE VIDRO
Quando inimigo entra em startup de ataque:
pequeno flash/brilho informativo.

Não aumentar mecanicamente reaction window.
É apenas clareza visual.

4. MOEDA VICIADA
Em cada draft:
permite 1 reroll da seleção inteira.

Se Trevo de Quatro Folhas estiver ativo:
reroll continua mostrando 4 cartas.

5. DENTE DE LOBO
Depois de evitar um ataque perigosamente próximo através de dash:
próximo ataque dentro de janela curta recebe área/slash levemente maior.

Não aumenta “dano”, porque UM CORTE é one-hit.

6. TALISMÃ DE FERRO
Reduz fortemente deslocamento recebido por:
- chutes
- knockbacks
- impulsos não-letais

7. INCENSO DA CALMA
Depois de permanecer parado brevemente:
arma o próximo parry.

O próximo parry recebe uma janela levemente maior.

Depois de usado:
precisa ficar parado novamente para rearmar.

--------------------------------------------------

RELÍQUIAS RARAS:

8. TREVO DE QUATRO FOLHAS
Drafts mostram 4 opções em vez de 3.

9. D6
1x por PARTIDA.

Jogador escolhe UM Legado próprio elegível.

Esse Legado é temporariamente rerrolado para outro Legado ALEATÓRIO da MESMA raridade durante aquela partida.

No fim da partida:
Legado original volta.

Excluir:
- o próprio D6
- Legados incompatíveis com modo
- Legados já possuídos

10. RELÓGIO PARADO
Perfect Parry:
gera breve slow-motion dos inimigos/mundo hostil.

Jogador permanece praticamente normal.

Usar cooldown interno pequeno para não ficar permanente em cadeias absurdas.

11. ESPELHO PARTIDO
1x por PARTIDA.

Quando adversário usa uma habilidade/especial próximo:
Espelho pode memorizar aquela habilidade.

Próxima ativação do slot do Espelho:
executa UMA cópia da habilidade.

Depois:
Espelho fica gasto até próxima partida.

Não copiar:
- transformações persistentes impossíveis
- recursos exclusivos de boss que não façam sentido
- efeitos que quebrariam estado do jogo

12. CARTA MARCADA
Durante um draft:
jogador pode marcar uma das opções rejeitadas.

A carta marcada é garantida em um draft futuro válido da mesma run.

Quando reaparece:
marca é consumida.

Se ela deixar de ser elegível:
rerrolar de maneira segura.

13. AMPULHETA DO SOBREVIVENTE
1x por PARTIDA.

Se o jogador passar extremamente perto de um ataque letal sem ser atingido:
acionar micro slow-motion automático por alguns décimos.

14. ÍMÃ DA FORTUNA
Se um draft contiver uma carta Lendária:
pelo menos UMA das outras opções deve ser Rara ou melhor.

--------------------------------------------------

RELÍQUIAS LENDÁRIAS:

15. PEDRA FILOSOFAL
USO ÚNICO POR RUN.

Ao ativar:

- escolher ALEATORIAMENTE um Legado próprio que possa subir de raridade;
- jogador NÃO escolhe qual;
- transformar ALEATORIAMENTE esse Legado em outro da categoria/raridade superior adequada;
- transformação dura apenas a PARTIDA atual;
- ao terminar a partida, Legado original volta;
- Pedra Filosofal permanece consumida pelo resto da run.

Common -> Rare
Rare -> Legendary

Não selecionar Legendary como alvo, pois não há tier acima.

Ao usar:
Pedra deve quebrar/desintegrar visualmente.

16. COROA DO CONQUISTADOR
No Caminho do Guerreiro:

ao derrotar Miniboss:
permitir roubar UM dos Legados que ele possuía.

Esse Legado é adicionado permanentemente à build daquela run.

Não substituir o draft normal.

É uma recompensa extra.

Em modos sem Miniboss:
não oferecer a Coroa no pool normal, salvo Admin.

17. CONTRATO DO DIABO
Funciona SOMENTE em drafts após Miniboss.

Normal:
escolhe 1 carta.

Com Contrato:
pode escolher 2 cartas.

Não funciona em Boss normal.
Não funciona em drafts comuns.

18. ORBE DO DESTINO
1x por RUN.

Durante um draft:
permite visualizar uma futura seleção válida de Legados.

Jogador pode:
- manter draft atual
OU
- substituir o draft atual pela seleção futura mostrada

Respeitar Trevo, pools, garantias e exclusões.

Depois:
Orbe fica consumido.

19. ANEL DA SEGUNDA CHANCE
1x por PARTIDA.

Quando jogador morrer em um duelo:

17. INTERAÇÕES ENTRE LEGADOS
======================================================================

FILOSOFIA FUNDAMENTAL:

Permitir combinações sempre que possível.

NÃO criar incompatibilidades artificiais apenas para facilitar código.

Não criar um sistema de “slots de corpo” limitando Vestimentas.

“você não pode usar X porque já tem Y”
salvo incompatibilidade REAL.

fazer a interação emergir naturalmente.

macaco recupera arma arremessada.

macaco pode roubar arma derrubada.

puxar arma jogada.

projétil entra em um e sai no outro.

arma atravessa portal.

ROOM + arma arremessada:
trocar posição com arma válida.

Botas-Foguete + double jump + air dash:
todos coexistem.

Sandevistan + técnicas:
técnicas continuam funcionando dentro do efeito temporal.

Se uma combinação realmente quebrar estado/física:
corrigir o caso técnico sem simplesmente proibir toda a combinação.

======================================================================

após Miniboss permite escolher duas.

Trevo:
aumenta número de opções mas não altera garantias negativamente.

D20:
não pode quebrar garantias obrigatórias.

======================================================================

PRIORIDADE ALTÍSSIMA.

======================================================================
43. REGRA ABSOLUTA DA IA
======================================================================

A IA NÃO PODE LER INPUT DO JOGADOR.

Não usar:

“player apertou ataque neste frame, então IA parry”.

IA pode reagir a:

- posição
- velocidade
- facing
- startup visível
- hitbox ativa
- projéteis existentes
- trajetória
- cooldown conhecido
- estado do cenário
- informações que um jogador humano poderia perceber

Ela pode prever trajetória a partir de:
posição + velocidade + contexto.

Não pode ter conhecimento mágico de input.

======================================================================
44. MOVIMENTO QUE A IA PRECISA DOMINAR
======================================================================

IA deve entender e usar:

- corrida
- jump
- double jump
- dash
- air dash
- dash ofensivo
- dash defensivo
- fast fall
- wall slide
- wall jump
- spacing
- reposicionamento
- cross-up
- perseguição aérea
- fuga aérea
- recuperação de queda
- plataformas
- rotas da arena

Double jump:
não gastar automaticamente ao sair do chão.

Air dash:
usar com intenção.

Fast fall:
usar para:
- mudar timing
- retornar ao chão
- escapar de ameaça aérea

Wall jump:
não ficar entrando em loop idiota contra parede.

======================================================================
45. COMBATE QUE A IA PRECISA DOMINAR
======================================================================

IA avançada deve:

- reconhecer alcance das armas
- respeitar recovery
- punir whiff
- evitar atacar sempre no primeiro instante possível
- usar parry lateral corretamente
- reconhecer cross-up
- preservar dash em certas situações
- baitar parry ocasionalmente
- recuar
- não atacar quando atacar seria ruim
- pressionar adversário vulnerável
- controlar distância
- reagir a projéteis
- entender hazards
- entender summons
- lidar com Legados

IA Mestre deve parecer boa,
não psychic.

======================================================================
46. DIFICULDADES DE IA
======================================================================

Fácil:

- reação lenta
- erros frequentes
- uso simples de dash
- pouco spacing
- desperdiça recursos
- ataques previsíveis

Normal:

- movimento razoável
- dash funcional
- parry razoável
- entende distância básica

Difícil:

- air dash
- double jump consciente
- fast fall
- whiff punish
- melhor spacing
- algumas fintas

Mestre:

- kit praticamente completo
- cross-ups
- resource management
- parry lateral avançado
- punição
- bait
- combina Legados
- sabe esperar
- sabe fugir
- comportamento menos previsível

Não reduzir dificuldade apenas a reaction time.

======================================================================

1–10:
mais simples.

11–20:
dash/spacing melhores.

21–30:

31–40:
combina movimento com Legados.

41–50:
próxima de Mestre completo.

Bosses:

59. ARMAS MÚLTIPLAS
======================================================================

pode escolher qual usar através do TAB.

mas permitir trocar antes do próximo duelo.

Não permitir troca livre no meio da luta,
salvo Legado futuro que explicitamente permita.

Todas as armas possuídas continuam aparecendo na lista de Legados.

======================================================================
60. SUMMONS — REGRAS GERAIS
======================================================================

Invocações hostis podem ser atingidas quando fizer sentido.

Por padrão:
um golpe limpo pode destruir uma summon vulnerável.

Matar summon:
NÃO vence o duelo.

Vitória continua ligada ao combatente principal.

Não permitir que ataques do próprio jogador matem seus companions,
salvo habilidade explicitamente projetada para friendly fire.

Exceção conhecida:
Dragão Ancestral pode criar região perigosa para o próprio invocador.

======================================================================
61. REWORK VISUAL DOS ATAQUES
======================================================================

Um dos objetivos visuais principais da V8.

Atualmente:
muitos ataques parecem “arma se move + trail”.

Quero linguagem visual mais próxima da ideia de Katana ZERO:

O CORTE deve parecer um objeto/forma visual própria no ar.

IMPORTANTE:

não copiar movimentação do Katana ZERO.
Apenas a linguagem visual do slash.

O personagem mantém movimentação UM CORTE.

O slash:

- nasce durante janela ativa
- é curto
- forte
- separado visualmente da arma
- corresponde aproximadamente à região real de perigo
- ajuda a ler hitbox

Exemplos:

Espada:
crescent/slash claro.

Machado:
arco mais grosso/pesado.

Ceifador:
grande curva longa.

Monge:
arco quase circular.

Lanceiro:
rasgo/linha de estocada.

Pugilista:
impacto curto/estouro, não crescent clássico.

Kunai/Arco:
projétil claro.

Golpes Lendários:
podem ter linguagem mais exagerada.

Não usar VFX gigantes que escondam gameplay.

O slash precisa melhorar leitura.

Não alterar silenciosamente hitbox só para combinar com efeito.
Ideal:
VFX representar a hitbox existente/intencional.

======================================================================

- joelhos mais ativos
- braços mais fortes
- cadência rápida

- sensação de esforço/velocidade

NÃO aumentar automaticamente:

- dash
- air dash
- demais classes

Preservar sistema universal de movimentação.
