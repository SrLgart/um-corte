# UM CORTE V8 — guia rápido

Caminho do Guerreiro, 115 Legados, novas arenas e bosses. Os dois arquivos da V8 podem ser abertos diretamente no navegador.

## Começar

Abra um-corte-v8.html no Chrome ou Edge. A edição um-corte-v8-admin.html acrescenta ferramentas administrativas. Para jogar com amigos, usem a mesma versão.

Um golpe limpo continua fatal. Legados específicos podem oferecer proteção ou segunda chance; não existe barra de vida.

## Controles padrão

| Ação | Teclado e mouse |
| --- | --- |
| Mover | A / D ou setas laterais |
| Mirar | Mouse |
| Pular / segundo pulo | W ou Espaço |
| Dash | Shift |
| Direção do dash aéreo | Movimento, incluindo W para cima |
| Descer / queda rápida | S ou seta para baixo |
| Ataque | Clique esquerdo ou J |
| Parry | Clique direito ou K |
| Chute | E ou L |
| Especial | F |
| Provocação | T |
| Inventário de Legados | Tab |
| Pausa / controles | Esc |

Você pode remapear os controles. No mesmo quadro, W + dash prioriza o dash para cima; um pulo executado antes não é desfeito. Habilidades ativas dos Legados recebem teclas próprias pelo botão MAPEAR no inventário. Confira cada carta para gestos e condições.

## Caminho do Guerreiro

Escolha os pontos por partida e clique em NOVA RUN. O padrão é primeiro a 3. São 50 níveis: perder uma partida encerra a tentativa, mas perder um duelo permite disputar os próximos pontos.

Você começa como Errante e constrói sua combinação de Legados. Em encontros de grupo, derrote todos os inimigos para pontuar. As escolhas de cartas do Caminho não têm prazo. Tab abre sua build e pausa a ação no solo.

As paredes laterais são contínuas: permitem wall jump e wall slide, mas não sair da arena saltando por cima delas.

CONTINUAR RUN recupera a tentativa neste navegador. Use o mesmo navegador e endereço de abertura para reencontrar o save. Apagar os dados do site remove a continuação. Uma derrota encerra a continuação normal.

O resultado reúne a build final, bosses enfrentados, duelos, inimigos derrotados e mortes. Os recordes deste navegador guardam vitórias, maior nível e melhor tempo de combate de uma run vitoriosa. Não concedem bônus nas próximas tentativas.

## Amigos assistindo

Durante a run, clique em CONVIDAR ESPECTADORES e compartilhe o código. Seu amigo usa ASSISTIR UM AMIGO no menu. Ele acompanha combate, escolhas e apresentações; não controla a run nem altera a build. A continuação pertence ao dono. Ao retomar um save, crie uma nova sala para os amigos.

A conexão depende das redes dos participantes. Testes locais não garantem conexão em todas as redes da Internet.

## Legados e laboratório

Em Personalizar partida → LEGADOS, escolha combate clássico, um Legado por partida ou um por duelo, cumulativo. A classe mantém seu especial; a arma equipada determina o ataque. No online, a escolha tem contador e confirmação automática ao terminar o prazo.

Tab mostra efeitos, recargas e usos. Quando habilidades disputarem o gesto de segurar pulo, escolha qual fica nesse gesto. No treino, o LABORATÓRIO permite experimentar o catálogo sem avançar na jornada.

Uma arma primária fica equipada por vez. Armas adicionais continuam na build e podem ser equipadas entre duelos. As nove primeiras habilidades ativas recebem atalhos numéricos disponíveis; se uma carta mostrar SEM TECLA, use MAPEAR para atribuir outro comando.

Nas cartas, “duelo” é a disputa de um ponto; “partida” é o confronto até o placar escolhido; “run” é toda a tentativa do Caminho. Um efeito de uso único por partida não recarrega só porque começou outro duelo.

No torneio, cada novo confronto começa uma nova build. No combate normal, os Legados continuam desligados por padrão.
